# Buraco Brusque

Aplicativo para celular (web, instalável no celular) "Buraco Brusque". O morador abre e vê um mapa de Brusque com os buracos informados e o total deles. Um botão grande "Informar buraco" pega a localização do aparelho, permite anexar uma foto opcional e enviar sem precisar de login. Página administrativa com login para o responsável da área: lista e mapa dos buracos, com foto, data e local; ações "Remover (falso)" e "Marcar como consertado". Os consertados somem do mapa público ou aparecem em outra cor. Evitar envios repetidos no mesmo lugar em pouco tempo.

Para definir antes:

Os moradores informam sem login, ou com algum cadastro simples, como o telefone?

Os buracos consertados somem do mapa ou ficam em verde?

Quem será o administrador? Pode ser mais de uma pessoa.
